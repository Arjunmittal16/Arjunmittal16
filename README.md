## My Projects
### 📡 [Wi-Fine](https://wi-fine.vercel.app/)
An offline AI chat app that runs entirely in your browser: no server, no internet needed once it loads. It runs a 4-bit **Llama 3.2 (1B/3B)** model locally through WebLLM and WebGPU with streaming responses, and supports **document Q&A** by extracting text from PDFs and images on-device with pdf.js and Tesseract.js OCR. Chat history stays private in IndexedDB. Built solo.

### 💬 Hamza
An LLM-powered Slack support agent I built and shipped at Morphic. It handled **1,000+ inbound queries** across 50+ conversations and cut median response time by **50%**, backed by an evaluation pipeline that tracked task completion, response quality, and failure modes, lifting agent success rate by **37%**.
